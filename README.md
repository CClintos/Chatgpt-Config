# Codex Efficient Workspace

Portable, private-by-default Codex project configuration for evidence-led SEO, car-audio measurement, Skill maintenance, MSP troubleshooting, and technical research.

The design target is useful completed work per Work/Codex allowance. It keeps the primary worker on GPT-6 Luna High, uses explicit custom agents for bounded escalation, and treats Astra as an exceptional reviewer rather than a default worker.

This repository contains instructions and templates, not credentials. Authenticate separately on each PC and keep browser sessions, API keys, cookies, passwords, MFA seeds, certificates, and client secrets out of Git.

Start with [START-HERE.md](START-HERE.md). Current OpenAI documentation references and the limits of what can be verified are recorded in [docs/MODEL-ROUTING.md](docs/MODEL-ROUTING.md).
