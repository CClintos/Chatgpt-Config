# Multi-PC setup

## Portable

- Git repository files: `AGENTS.md`, `.codex/config.toml`, `.codex/agents/`, `.agents/skills/`, state/log templates, handoffs, and validation tests.
- Relative paths only; no machine-specific home directory or browser profile is required.

## Still local to each PC

- Codex/ChatGPT sign-in, plan access, usage limits, trust approval, and user-level `~/.codex/config.toml`.
- Browser/app authentication to WordPress, cPanel, Search Console, Google Business Profile, Microsoft services, GitHub, and any client system.
- Installed software such as REW, UMIK-1 drivers/calibration, Helix software, PowerShell/Python, and any approved local MCP/apps.
- OS permissions, Windows sandbox availability, audio hardware, local measurement files, and private worktree settings.

Never copy cookies, browser sessions, tokens, MFA seeds, or credentials between PCs via Git.
